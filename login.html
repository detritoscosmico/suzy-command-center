Proteções e limites

  • Funciona apenas com npm run serve:secure.
  • Senhas são derivadas com PBKDF2; a chave de recuperação é armazenada somente como hash.
  • Alterar ou recuperar a senha encerra todas as sessões anteriores.
  • O GitHub Pages continua sendo uma demonstração pública sem backend.
  • O banco fica em data/suzy-local.sqlite3 e não é enviado ao GitHub.
