# SUZY COMMAND CENTER — PAINEL DE ATIVOS

Projeto pronto para abrir no VS Code.

## Como rodar

1. Clone ou baixe o repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito e escolha `Open with Live Server`.

Sem o Live Server, abra `index.html` diretamente no navegador.

## Recursos atuais

- Lista de ativos OTC.
- Índices, criptomoedas, ouro e moedas.
- Busca por nome ou ticker.
- Filtro por categoria.
- Ordenação por popularidade e volatilidade.
- Conta demo, últimos sinais e missão do dia.
- Layout responsivo.

## Aviso

Este painel é visual e demonstrativo. Não conecta à IQ Option e não executa operações reais.
